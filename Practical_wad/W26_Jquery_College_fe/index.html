First Year (FE)

Engineering Mathematics
Basics of calculus and algebra.
Engineering Physics
Concepts of mechanics and optics.
Basic Electronics
Introduction to circuits and devices.
Programming in C
Fundamentals of programming.

Second Year (SE)

Data Structures
Arrays, linked lists, trees.
Computer Organization
CPU, memory, and architecture.
Discrete Mathematics
Logic, sets, and relations.
Object Oriented Programming
Concepts using C++/Java.

Third Year (TE)

Operating Systems
Process, memory, scheduling.
Database Management
SQL, normalization, transactions.
Computer Networks
OSI model and protocols.
Software Engineering
Development lifecycle models.

Final Year (BE)

Machine Learning
Algorithms and data analysis.
Cloud Computing
Virtualization and cloud services.
Cyber Security
Threats and protection techniques.
Project Work
Final year major project.
