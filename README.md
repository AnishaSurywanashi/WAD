### ✅ Assignment 2: User Registration System
**Description:**
- Developed a complete **User Registration Form**
- Applied **JavaScript validations**
- Used **AJAX POST method** for data submission
- Stored data using **localStorage**
- Displayed registered users on a separate page

**Features:**
- Name, Mobile, Email, Password validation
- Gender and Hobbies selection
- Confirmation box before submission
- Data displayed in tabular format

**Technologies Used:**
- HTML  
- CSS  
- JavaScript  
- AJAX  
- localStorage
